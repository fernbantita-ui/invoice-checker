ตรวจสอบใบเสร็จ ปตท.บริหารธุรกิจค้าปลีก

ตรวจเฉพาะใบเสร็จของ บริษัท ปตท.บริหารธุรกิจค้าปลีก จำกัด — เช็คว่าเป็นเอกสารของผู้ออกจริง ชื่อ+ที่อยู่ลูกค้าครบถ้วนสะกดถูก อ่านรหัสสาขาจากตราปั๊ม แล้วเลือกยอดเงินตามวันที่ที่กำหนด (วันที่บนใบนี้เป็น ค.ศ. ไม่ใช่ พ.ศ.)

ประมวลผลในเบราว์เซอร์ทั้งหมด — ไฟล์ไม่ถูกส่งขึ้นเซิร์ฟเวอร์

1 · ผู้ออกใบเสร็จ (ต้องเป็นเอกสารของ ปตท.บริหารธุรกิจค้าปลีก)

แค่เช็คว่ามีเลขผู้เสียภาษี + มีคำในที่อยู่ + มีข้อความ "สาขาที่ออกใบกำกับภาษี" อยู่ในเอกสารหรือไม่ ถ้าไม่ผ่านจะไม่นับเป็นเอกสารของผู้ออกรายนี้ และไม่รวมใน Excel สรุป

2 · ข้อมูลลูกค้า (ปตท. น้ำมันฯ) — เน้นตรวจชื่อเป็นพิเศษ

กรุงเทพฯ/กรุงเทพมหานคร ถือว่าเหมือนกัน — ชื่อบริษัทให้น้ำหนักคะแนนสูงสุดในการคำนวณคะแนนรวม

3 · วันที่ใช้ตัดสินยอดเงิน

วันที่บนใบเสร็จนี้เป็นปี ค.ศ. (เช่น 2026) ไม่ใช่ พ.ศ. — ต่างจากใบเสร็จ CP ALL
ถ้าที่อยู่/ชื่อลูกค้าถูกต้อง + วันที่ไม่เกินกำหนด → ใช้ "รวมรายการ ที่มีภาษีมูลค่าเพิ่ม" (รวม VAT)
ถ้าผิดเงื่อนไขใดก็ตาม → ใช้ "จำนวนเงินรวมก่อนภาษีมูลค่าเพิ่ม" (ตัด VAT ออก)

4 · อัปโหลดเอกสาร (PDF)

คลิกเพื่อเลือกไฟล์ หรือลากไฟล์ PDF มาวางที่นี่

ยืนยันถูก: 0 แก้ไขผิด: 0
ยังไม่มีผลลัพธ์ — อัปโหลดไฟล์ PDF แล้วกด "ตรวจสอบเอกสารทั้งหมด"
OCR ภาษาไทยทำงานผ่าน Tesseract.js (WebAssembly) ในเบราว์เซอร์ของคุณโดยตรง — การโหลดโมดูลภาษาไทยครั้งแรกอาจใช้เวลาสักครู่
เรื่องการ "เทรน": ปุ่ม ✓/✗ บันทึกกฎยกเว้นในเบราว์เซอร์ (ไม่ใช่โมเดล AI จริง) จำนวนครั้งสะสมอยู่มุมซ้ายและใน Excel ชีท "สถิติการเทรน"
รหัสสาขา: แยกหมึกแดง/ชมพูของตราปั๊มออกมา OCR สองรอบ (ทั้งตรา + เฉพาะบรรทัดรหัส) แล้วโหวตหา "SC ####" — ช่องขาว = สองรอบอ่านตรงกัน, ช่องเหลือง = ไม่แน่ใจ, ช่องแดง = อ่านไม่ได้ · พิมพ์แก้ในช่องรหัสสาขาได้เลย (กดที่แถวเพื่อดูรูปตราปั๊ม) ค่าที่แก้จะไปอยู่ใน Excel
ต้นฉบับ/สำเนา: อ่านจากคำที่พิมพ์บนเอกสาร เช่น "(ต้นฉบับ-ลูกค้า)" หรือ "สำเนา" — มี (?) ต่อท้ายถ้า OCR อ่านคำไม่ชัด ไม่สามารถบอกได้ว่าเป็นเอกสารที่ถ่ายเอกสารมาจากต้นฉบับหรือไม่
ยอดเงิน: ใช้สองวิธีร่วมกัน (1) หาเลขติดกับป้ายชื่อ (2) นับตำแหน่งจากท้ายกลุ่มตัวเลข 7 ค่าสุดท้ายในหน้า เผื่อ OCR อ่านคอลัมน์ป้ายชื่อกับตัวเลขแยกกัน — ควรตรวจทานก่อนใช้งานจริง
Excel: ชีทหลัก "สรุป" มีเลขที่บิล/รหัสสาขา/ยอดเงิน/สถานะ VAT — ชีท "รายละเอียด" มีข้อมูลตรวจสอบทั้งหมดไว้ตรวจทาน
