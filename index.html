CP ALL / 7-Eleven Receipt · OCR Verification

ตรวจสอบใบเสร็จ/ใบกำกับภาษี CP ALL

ตรวจเฉพาะใบเสร็จ บมจ.ซีพี ออลล์ — เช็คว่าเป็นเอกสารของผู้ออกจริง ชื่อ+ที่อยู่ลูกค้าครบถ้วนสะกดถูก อ่านเลขสาขาจากช่อง "สาขาที่ออกใบกำกับภาษี" แล้วเลือกยอดเงินตามวันที่ที่กำหนด

ประมวลผลในเบราว์เซอร์ทั้งหมด — ไฟล์ไม่ถูกส่งขึ้นเซิร์ฟเวอร์

1 · ผู้ออกใบเสร็จ (ต้องเป็นเอกสารของ CP ALL)

แค่เช็คว่ามีเลขผู้เสียภาษี + มีคำในที่อยู่ + มีข้อความ "สาขาที่ออกใบกำกับภาษี" อยู่ในเอกสารหรือไม่ ถ้าไม่ผ่านจะไม่นับเป็นเอกสาร CP ALL และไม่รวมใน Excel สรุป

2 · ข้อมูลลูกค้า (ปตท.) — เน้นตรวจชื่อเป็นพิเศษ

กรุงเทพฯ/กรุงเทพมหานคร ถือว่าเหมือนกัน — ชื่อบริษัทให้น้ำหนักคะแนนสูงสุดในการคำนวณคะแนนรวม

3 · วันที่ใช้ตัดสินยอดเงิน

ถ้าที่อยู่/ชื่อลูกค้าถูกต้อง + วันที่บนใบเสร็จไม่เกินวันที่กำหนด → ใช้ "ยอดรวมทั้งสิ้น" (รวม VAT)
ถ้าชื่อ/ที่อยู่ผิด หรือวันที่เกินกำหนด → ใช้ "มูลค่าสินค้าก่อนภาษีมูลค่าเพิ่ม" (ตัด VAT ออก)

4 · อัปโหลดเอกสาร (PDF)

คลิกเพื่อเลือกไฟล์ หรือลากไฟล์ PDF มาวางที่นี่

เก็บสถิติสะสมในเบราว์เซอร์นี้ — ยืนยันถูก 0 แก้ไขผิด 0

5 · ประวัติการตรวจ

บันทึกไว้ในเบราว์เซอร์นี้ทุกครั้งที่กด "ตรวจสอบเอกสารทั้งหมด" — ดูย้อนหลังและดาวน์โหลด Excel ของแต่ละรอบได้ กรองตามผู้ตรวจได้

ยังไม่มีผลลัพธ์ — อัปโหลดไฟล์ PDF แล้วกด "ตรวจสอบเอกสารทั้งหมด"

เอกสารที่เป็นสำเนา 0

OCR ภาษาไทยทำงานผ่าน Tesseract.js (WebAssembly) ในเบราว์เซอร์ของคุณโดยตรง — การโหลดโมดูลภาษาไทยครั้งแรกอาจใช้เวลาสักครู่
สิ่งที่แก้รอบนี้: (1) การดึงยอดเงินตอนนี้ใช้สองวิธีร่วมกัน — หาเลขติดป้ายชื่อก่อน ถ้าไม่เจอ (เพราะ OCR อ่านคอลัมน์ป้ายชื่อกับตัวเลขแยกกัน) จะนับตำแหน่งจากท้ายกลุ่มตัวเลข 7 ค่าสุดท้ายแทน ซึ่งเป็นโครงสร้างตายตัวของใบเสร็จ CP ALL เสมอ — ทดสอบแล้วทั้งสองกรณี (2) เพิ่มคอลัมน์ "เลขสาขา" อ่านจาก "สาขาที่ออกใบกำกับภาษี : #####" ที่พิมพ์อยู่บนใบทุกใบ (ไม่ใช่จากตราปั๊มสี เพราะแบบฟอร์มนี้ไม่มี)
เรื่องการ "เทรน": ปุ่ม ✓/✗ บันทึกกฎยกเว้นลงในเบราว์เซอร์แบบถาวร (ใช้ localStorage-like API สะสมไปเรื่อยๆ ไม่หายเมื่อกด "ล้างทั้งหมด" หรือปิดหน้าเว็บ — หายเฉพาะถ้าล้างข้อมูลเบราว์เซอร์เท่านั้น) จำนวนครั้งสะสมโชว์อยู่มุมซ้ายบนของกล่องอัปโหลด — **ขอย้ำอีกครั้งว่านี่ไม่ใช่ AI ที่เทรนโมเดลจริง** เป็นแค่รายการคำที่ยืนยัน/ปฏิเสธไว้ใช้ในการจับคู่ครั้งต่อไป
Excel: ชีท "รายละเอียด" มีข้อมูลตรวจสอบทั้งหมดไว้ตรวจทาน — ชีท "กรอกเอกสาร" กรอก CODE/ชื่อร้าน/ผู้จัดการเขตให้อัตโนมัติถ้าจับสาขาได้
